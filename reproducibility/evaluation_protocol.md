# Pre-specified evaluation protocol (Step 251)

**TensorGuard pre-specified evaluation protocol v1.0.0** registers the case splits, tuning locks, metric formulas, and analysis scripts used by downstream TensorGuard evaluations. It is a methodology artifact, not a scorer: generated outputs below are hashes, counts, formulas, and consistency checks.

> Historical pre-registration is established by git history: this protocol commit must predate future scoring-result commits. The reproduction-order check below is a consistency guard for one-command rebuilds, not a substitute for temporal provenance.

## Metric definitions

| metric | formula |
| --- | --- |
| recall_on_decided | TP / (TP + FN), excluding UNKNOWN verdicts from the denominator |
| recall_on_all_buggy | TP / all buggy cases, counting UNKNOWN as not caught |
| specificity_on_decided | TN / (TN + FP), excluding UNKNOWN clean verdicts |
| false_positive_rate | FP / (FP + TN) on clean cases with definite verdicts |
| precision | TP / (TP + FP) over positive UNSAFE predictions |
| abstention_rate | UNKNOWN verdicts / cases in the evaluated split |
| wilson_95_ci | Wilson score interval with z=1.959963984540054 |
| paired_mcnemar | exact paired McNemar over discordant correctness counts b,c |
| paired_effect_size | Cohen's g, Haldane-Anscombe odds ratio, risk difference |
| power_and_sample_size | exact binomial power / rule-of-three / McNemar discordant floor |
| overfitting_gap | abs(blind recall_on_decided - development recall_on_decided) |
