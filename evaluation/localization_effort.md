# Localization-effort proxy — does TensorGuard help developers localize bugs?

_Generated by `evaluation/localization_effort.py` from `reproducibility/localization_marker_only_n30.json`. Do not edit by hand._

- Bugs analyzed: **14** (refuted real bugs with a `# BUG` marker)
- Measure: lines a developer inspects to reach the true bug; assisted = dist_v5 + 1 (scan outward from TG's reported line); unaided = (N+1)/2 expected linear scan over N executable lines
- Design: paired, within-bug; same line unit for both arms

> **Proxy, not an RCT.** This is a localization-effort proxy on the frozen corpus, not a human RCT. The pre-registered human study is specified in docs/user_study/protocol.md. Bugs where TG misleads are kept.

## Headline

- Median lines inspected: **2.0** with TensorGuard vs **7.5** unaided.
- Median per-bug reduction factor: **3.0×** (95% bootstrap CI 1.33125–5.875×).
- Cliff's delta: **0.627551** (large; 95% CI 0.219388–0.979592).
- Cohen's d: 1.447065 (large); Hedges' g: 1.404918 (large).
- TensorGuard reduced effort on **12/14** bugs and increased it on 2 (kept, not hidden).
