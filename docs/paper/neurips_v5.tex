\title{TensorGuard v5: Refinement-Typed Shape and Gradient
  Verification for \texttt{nn.Module} Composition,
  with a Dynamo-Guard Correspondence}

\author{Anonymous Authors\\Submission under double-blind review}

\begin{document}
\maketitle

\begin{abstract}
We present \textsc{TensorGuard}~v5, a sound static verifier for
PyTorch \verb|nn.Module| classes built around a refinement-typed
calculus that unifies symbolic shape analysis and static
gradient-flag analysis under a single metatheory. Tensor types
are refinement records over symbolic shape, gradient-required
flag, and a Z3-decidable side condition; module composition is
checked locally as an assume/guarantee discipline at the class
boundary; an autograd-aware backward verifier catches the
canonical silent-zero-grad bugs (in-place leaf write,
\texttt{.detach()} on the loss path, \texttt{torch.no\_grad()}
scope error) statically. We prove a one-to-one correspondence
between the refinements \textsc{TensorGuard} discharges and the
guards TorchDynamo would install on the same trace, and report
empirical agreement on a benchmark of $\geq 150$ verification
blocks drawn from torchvision, HuggingFace Transformers, timm,
and a curated bug-injection suite. A Lean~4 parity development
machine-checks $20$ operator transfer-function lemmas with no
\texttt{sorry} and no \texttt{mathlib} dependency. Out-of-fragment
constructs trigger explicit abstention, reported as a
first-class verdict.
\end{abstract}
