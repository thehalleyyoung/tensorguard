# The CEGAR predicate-discovery loop and its convergence

TensorGuard's shape verifier is sound on its own; the CEGAR (counterexample-
guided abstraction refinement) layer in `src/shape_cegar.py` makes it *more
precise* without sacrificing that soundness, by discovering the shape predicates
needed to discharge spurious counterexamples. This document specifies the loop,
states its convergence theorem, and reports **measured** iteration counts from
running the real loop on the frozen corpus.

## 1. The loop

```
seed   P_0  <- harvest guards (asserts, if-conditions on .shape, layer arities)
repeat:
    r <- model-check the module under the current predicate set P_i
    if r is SAFE:                 return SAFE              # all CEX eliminated
    if r's counterexample is a real bug (concrete, feasible input):
                                  return REAL_BUG_FOUND
    # otherwise the counterexample is spurious:
    p  <- predicates that make the spurious CEX infeasible   (unsat-core based)
    P_{i+1} <- P_i u {p}          # strictly grows the predicate set
until budget exhausted -> MAX_ITER (reported as TIMEOUT, never as SAFE)
```

Two properties make this sound and terminating:

- **Monotonicity (Houdini-style).** Each refinement iteration adds at least one
  *new* predicate from the finite program predicate universe `P_prog`, or the
  loop terminates. The accumulated set therefore grows strictly until it
  saturates.
- **Soundness of termination.** SAFE is only returned when no counterexample
  remains; a real (feasible) counterexample short-circuits to UNSAFE; budget
  exhaustion returns TIMEOUT/UNKNOWN, never SAFE. So refinement can only ever
  *remove* false alarms, not introduce missed bugs.

## 2. Convergence theorem

The naive bound is the size of the whole predicate universe,
`|P_prog| = |E| x (predicate kinds)` (edges times kinds), which is large. The
tight bound in `src/cegar_convergence_theory.py` is far smaller:

> **Tight CEGAR Convergence via Predicate Coverage.** Let `P_seed` be the
> predicates extractable from source-level guards and `P_final` the predicates at
> termination. The loop terminates in at most `k = |P_final \ P_seed|`
> iterations, and `k <= (1 - coverage) x |P_prog|` where
> `coverage = |P_seed n P_final| / |P_final|`.
>
> *Proof sketch.* Seeds are loaded at iteration 0, so only predicates in
> `P_final \ P_seed` remain to be discovered; each iteration adds at least one,
> so after `k` of them the set saturates and the loop converges.

**Corollary.** When guard harvesting captures most predicates (`coverage` near
1), `k` is near 0 and CEGAR converges in O(1) iterations; the adversarial case
(`coverage` near 0) recovers the naive `|P_prog|` bound.

## 3. Measured convergence (real loop, frozen corpus)

The theorem is validated empirically by
[`reproducibility/cegar_convergence.py`](../../reproducibility/cegar_convergence.py),
which *runs the real `run_shape_cegar` loop* on every model in the frozen
`real_benchmarks` corpus and checks, per model:

1. the tight prediction `iterations <= 1 + |discovered_predicates|` (one terminal
   iteration past the last predicate-adding refinement), and
2. that observed iterations stay far below the naive `layers x dims x 7` bound.

The generated table is
[`reproducibility/cegar_convergence.md`](../../reproducibility/cegar_convergence.md).
Headline numbers (regenerated byte-identically by
`reproducibility/reproduce_all.py --check`):

- 16 models, iterations observed in **{1, 2}** (max 2, mean about 1.1).
- At most **one** predicate discovered on any model.
- The tight bound `iterations <= 1 + |discovered_predicates|` holds on **every**
  model; every run is **one to two orders of magnitude** below its naive
  predicate-universe bound.

This matches the high-coverage regime the corollary predicts: layer arities and
source guards already pin down nearly all shape predicates, so the loop rarely
needs to refine.

### Honest scope

The corpus is small (16 frozen models, shape-dominated). The measurement
*confirms* the theorem holds where we can run it and that the naive bound is
loose in practice; it does not claim the worst case never occurs. The worst case
is exactly the `coverage` near 0 branch of the corollary, which recovers the
naive bound and is bounded by the finite predicate universe — so termination is
guaranteed regardless.
