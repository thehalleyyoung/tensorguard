# TensorGuard — Artifact Evaluation: STATUS

We are applying for the following ACM SIGPLAN/SIGSOFT Artifact Evaluation
badges:

- **Artifacts Available** — the artifact is publicly archived at a stable,
  citable location.
- **Artifacts Evaluated — Functional** — the artifact is documented,
  consistent, complete, and exercisable: every quantitative claim in the paper
  is regenerated from source by a single command.
- **Artifacts Evaluated — Reusable** — the artifact is engineered for reuse:
  it is a `pip`-installable, PEP 561-typed Python package with a public API, a
  pinned reproducible container image, a labeled benchmark corpus with an
  integrity manifest, and machine-checked Lean soundness proofs.

## Why we believe each badge is met

### Available
- Source: <https://github.com/thehalleyyoung/tensorguard> (MIT licensed).
- Each release is tagged and the container image is published to GHCR
  (`ghcr.io/thehalleyyoung/tensorguard`), built reproducibly with
  `SOURCE_DATE_EPOCH` (see `Dockerfile`).
- The benchmark corpus is frozen with a SHA-256 manifest
  (`real_benchmarks/manifest.json`) so it is independently citable
  (see `docs/artifact/README.md`, claim table).

### Functional
- `python reproducibility/reproduce_all.py` regenerates, in dependency order,
  every CI-reproducible artifact (spec docs, the frozen corpus + audit, the
  headline Refuted-Proof figure, and the **paired significance tests**) and then
  runs the numeric-claim audit, which recomputes every `x/y` ratio and percent
  token in `README.md` from the freshly regenerated artifacts. The harness
  exits non-zero on any mismatch.
- `python reproducibility/reproduce_all.py --check` additionally asserts
  **determinism**: re-running must leave the byte-deterministic generated paths
  with zero `git diff`.
- Honest scoping: artifacts requiring CUDA, a HuggingFace download, or the Lean
  toolchain are validated against their committed copies in a standard CI box
  and regenerated by `make reproduce-full` in an environment that has those
  toolchains. The audit labels their claims `QUALIFIED_ENV` and records the
  exact regeneration command.

### Reusable
- `pip install tensorguard` exposes a typed public API
  (`verify_architecture`, `py.typed`); see `README.md`.
- The Lean soundness proofs build sorry-free and are axiom-audited
  (`lean/TensorGuard/AxiomAudit.lean`, `tests/test_lean_soundness.py`).
- Coverage, multi-OS/Python/PyTorch CI, and community-health files are in place
  (`.github/workflows/`, `CONTRIBUTING.md`, `GOVERNANCE.md`).

## One-line smoke test (functional)

```bash
docker run --rm -v "$PWD:/work" ghcr.io/thehalleyyoung/tensorguard verify /work/examples/shape_bug.py
```

or, from a source checkout:

```bash
python reproducibility/reproduce_all.py --check
```
